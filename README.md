# LedgerLine

### Secure Money Movement with a Verifiable Ledger

LedgerLine is a secure financial transaction management system designed to prevent duplicate payments, unauthorized transactions, and incorrect account balances.

## Project Overview

The main goal of LedgerLine is to ensure that every financial transaction is accurate, secure, and traceable.

## Key Objectives

- Secure user authentication and authorization.
- Account creation and balance management.
- Deposits, withdrawals, and fund transfers.
- Double-entry ledger for financial records.
- Prevention of duplicate transactions using idempotency.
- Concurrency-safe money transfers.
- Transaction history and audit tracking.

## Technology Stack

- Java
- Spring Boot
- PostgreSQL
- Spring Security
- JWT Authentication
- React
- Tailwind CSS

## User Roles

- ADMIN – Manages users and accounts.
- CUSTOMER – Performs permitted account operations.
- AUDITOR – Views financial records in read-only mode.
